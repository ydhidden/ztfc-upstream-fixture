# ztfc-upstream-fixture

A **test fixture** for the zero-trust contribution workflow in [imboard-ai/ai-dossier](https://github.com/imboard-ai/ai-dossier). It is the controlled "upstream" in the GitHub credential feasibility probe ([ai-dossier#1011](https://github.com/imboard-ai/ai-dossier/issues/1011)).

It plays the role of a third-party open-source project that has **not** installed the contributor tool's GitHub App. A separate contributor test account forks it and opens pull requests from the fork, so the probe can record exactly which writes GitHub allows.

This is not a real library. Issues and PRs here are generated by the probe and may be closed without review.
